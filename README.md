## 本次统一明确的原则

- **一般性规则优先于样例。** 样例用于说明规则的具体实现；局部展示三个词，不意味着实际只能解释三个词。示例中的字面词语不自动构成禁词表。
- **保留明确偏好，让模型判断合适颗粒度。** 六词上限、最多新增三个词等明确要求继续保留；代码块大小、代表例题数量等结合实际内容判断。
- **分批生成用于保障质量。** 正文连续产出，供全部生成后集中阅读，不在各批之间安排理解确认或小测试。
- **以知识和作用覆盖为准。** 教材中的重复表述可以合并；同一函数在不同位置承担不同作用时，需要分别解释。
- **基础按实际内容处理。** 常规本科数学不反复科普，小公式和条件适当提醒，陌生前置内容作够用的补充，不强行按学段给课程归类。

## 教材文稿的两种顺序

生成：正文各 Part → The Grand Map → The Algorithm Toolkit → The Executive Briefing。

保存与阅读：The Executive Briefing → 正文各 Part → The Grand Map → The Algorithm Toolkit。

宏观地图负责建立整体联系；综合案例负责把本章分散的方法共同用起来；阅前简报根据实际完成的文稿提供阅读导向。

## 词义样例的校准依据

Obtain 的取得义不包含“必须合法合规”的保证，Acquire 的用法也不能一律解释为长期、永久的内化。因此，修订保留专业例句的形式，同时让词义归纳与实际用法一致。参见 [Cambridge：obtain](https://dictionary.cambridge.org/dictionary/english/obtain)、[Cambridge：acquire](https://dictionary.cambridge.org/dictionary/english/acquire)。

其余选词标签也按典型侧重点表述，并保留必要的重叠说明，尤其不将 Achieve 与 Attain 强分为互斥关系。参见 [Cambridge：get](https://dictionary.cambridge.org/dictionary/english/get)、[gain](https://dictionary.cambridge.org/dictionary/english/gain)、[achieve](https://dictionary.cambridge.org/dictionary/english/achieve)、[attain](https://dictionary.cambridge.org/dictionary/english/attain)。
