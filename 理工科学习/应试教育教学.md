# 任务

我需要在很短时间内，从缺乏可直接使用的基础出发，快速掌握一个有明确考核指标的任务。典型情境是用过去试卷准备考试：在有限时间内尽可能提高预期总分，能够完成原题，以及改变数据或表述但考查知识相同的变式。

任务、材料、可用时间和指标以当次输入为准。未另行指定时，以零基础、八小时可用学习时间作为速通安排的参考。不限课程或学段。

以下一般性规则优先于例子。例子说明适用情境，不把某一门课程、某种题型或工具固定为唯一范围。

# 取舍原则

- 根据提供的试卷、考核要求和当前基础，自行判断学习优先级与时间安排，以有限时间内的预期总分为准。不按题目的表面难度或知识的理论地位决定轻重。
- 围绕目标进行有意识的“过拟合”：优先学会原题及近似变式，少花时间扩展暂时不能帮助完成目标的理论。
- 对非考试任务，将“提分”对应为当次明确的考核指标，保持同样的短期速通取向。

# 教学要求

输出一份可以连续阅读的完整教学讲义，而非每讲一点就停下来提问或测试。

对选中的每类问题，讲到我能照着完成、并能处理相关变式：

1. **识别信号：** 从题干、数据形式或目标判断它属于哪类问题，该用什么方法。
2. **最少必备知识：** 只补完成本类题目所需的概念和规则。第一次使用一个我尚未接触的概念前，先用足够直接的解释让我知道它是什么、怎么用。
3. **完整解题示范：** 从输入到答案逐步展开，重要的代入、计算、判断和中间结果不能跳过。不要用另一个没介绍过的概念解释当前概念。
4. **变式处理：** 指出换数据、换表述或改变题面后，哪些步骤不变、哪些地方要重新判断。不要只给可以机械背诵的原题答案。
5. **易错点与检查：** 提醒会导致失分的条件、边界和常见错误，并给出实际可用的检查方法。

概念和步骤要够用、清楚；不为完整介绍学科体系而展开与当前解题无关的基础理论或历史。重复使用的知识可以合并说明，但不能漏掉新的操作条件。

# 讲义组织与图示

开头简要给出学习顺序与时间分配，然后立即进入教学。可以合并重复题型，避免对同一方法反复从头讲；仍应说明所覆盖的题目以及有意义的变式。

图像能明显降低理解成本时，使用图文结合。例如 B 树、B+ 树的结构与操作通常适合图示；能用几句话说清的内容不必为了可视化而画图。可使用当前环境支持的图形方式，包括合适的 HTML 图示。

讲义过长时，可按完整题型或学习模块分批生成，以保证每部分讲解充分；下一批连续推进，不把生成分批改成逐题问答。完整测试在讲义完成后、按我的要求另行安排。

结尾提供一份简明的识别与操作清单，方便考前快速回看。
